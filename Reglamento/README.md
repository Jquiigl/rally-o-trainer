# Reglamento estructurado de Rally O Trainer

## Propósito

Esta carpeta transforma reglas relevantes para el producto en datos trazables. No sustituye los PDF oficiales ni pretende interpretar casos de juicio. La prioridad editorial es RSCE; FCI actúa como marco internacional y como fuente de las señales internacionales.

## Regla editorial

- El texto mostrado en la aplicación es redacción propia fiel a la fuente.
- Una regla conserva autoridad, documento, página y fecha de vigencia.
- Una actualización crea una revisión nueva; no reescribe evidencias históricas.
- Las restricciones del planificador se derivan de `progression.json`, pero nunca bloquean la consulta manual.
- Antes de publicar un paquete de contenido, el propietario debe revisar las diferencias contra los PDF originales.

## Límites

El producto no determina sanciones, aptitud para competir ni decisiones de un juez. Cuando exista contradicción, prevalece el reglamento oficial vigente publicado por RSCE o FCI.
